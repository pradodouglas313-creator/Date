MeuDate
Protótipo estático do MeuDate (modo offline + export/import).
Abra index.html (ou publique via GitHub Pages) para usar.

Funcionalidades:

Criar convite (salvo no navegador)
Exportar convite (.json) e importar em outro dispositivo
Aceitar convite via /d/<CÓDIGO> (resposta salva no navegador)
Painel para listar/importar/exportar/apagar convites locais
Publicação:

Recomendo usar GitHub Pages. Após colocar os arquivos no repo, a URL provável é: https://.github.io/Date
